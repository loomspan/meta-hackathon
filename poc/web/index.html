Connect Loomspan (POC)

This is a public proof-of-concept page. It connects Muse or ChatGPT web to the Loomspan MCP server so the companion can open your Loomspan apps. One connection serves all apps; do not repeat this setup per app.

Loomspan MCP server URL

Both companions need this server URL:

https://yjrwyfkybszlpufsflan.supabase.co/functions/v1/mcp

Muse (muse.ai)

  1. Open Muse at muse.ai and start a new conversation.
  2. Add a custom or remote MCP connection using the Loomspan MCP server URL above. The exact menu labels in the Muse web UI were not verified against the live product during this POC build; use its custom/remote MCP connection option and paste the server URL there.
  3. When Muse asks you to sign in, sign in on the Loomspan consent page with your test account.
  4. Check that the consent page names the requesting client and the requested access, then approve.
  5. Return to Muse. The connection is ready; you do not need to connect again for each app.

ChatGPT web

  1. Open ChatGPT web and start a new conversation.
  2. Add a custom or remote MCP connection using the Loomspan MCP server URL above. The exact menu labels in the ChatGPT web UI were not verified against the live product during this POC build; use its custom/remote MCP connection option and paste the server URL there.
  3. When ChatGPT asks you to sign in, sign in on the Loomspan consent page with your test account.
  4. Check that the consent page names the requesting client and the requested access, then approve.
  5. Return to ChatGPT. The connection is ready; you do not need to connect again for each app.

Entry prompt

After connecting, paste this prompt into the companion:

Connect to Loomspan using the Loomspan MCP server, then open my grocery-list app.

If something fails

If sign-in or consent fails, stop and report what happened. Do not work around it by pasting secrets, tokens, or keys anywhere, and do not edit configuration files. A failure here is recorded as an authentication/integration failure with cause unconfirmed until it is investigated.
